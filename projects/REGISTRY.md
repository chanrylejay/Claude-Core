# Project registry — every project, one line, always current

The kit's map of Chan's projects. MEMORY.md indexes facts; DIRECTORY.md indexes kit files;
THIS file indexes PROJECTS — the missing third index (added Aug 28 2026 after Sonneto
Journal, a live shipped product, went two weeks unbanked while carrying the kit's own seed
file: workspaces knew the kit, the kit did not know the workspaces).

**Line format:** name · STATE · repo (visibility) · live URL if any · where context lives.
**States:** ACTIVE (getting hours now) · LIVE-DORMANT (shipped, running, not being worked) ·
PARKED (half-built, intentional pause) · ENDED (closed engagements; history).
**Laws:** public-safe always (private repos are named but never linked with anything
sensitive). A new project gets its line THE SAME SESSION it is first mentioned or created —
an unregistered project does not exist to the next session. The ACTIVE project additionally
gets a canon per the README's active-project canon law; registry line and `active_project`
in the state block change together. For PUBLIC repos the URL is the context: any claude.ai
session can clone and orient itself, no canon needed unless the project goes ACTIVE.
